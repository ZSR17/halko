# Adding a language

Halko is in English and French. English is the reference: any text missing in another language shows in
English, so a translation can be added little by little without breaking anything.

## 1. App texts

1. Copy `shared/src/i18n/messages/en.json` to `shared/src/i18n/messages/<code>.json` (`de.json`,
   `es.json`…, the two-letter ISO 639-1 code) and translate the values. Keep the keys, and the
   `{placeholders}` exactly as they are.
2. Texts with plural forms are objects, one entry per plural category of the language (`one`, `few`,
   `many`, `other`…, as [`Intl.PluralRules`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules)
   gives them). `other` is always required.
3. In `shared/src/i18n/index.ts`, import the file, add a line to `LOCALES` with the language's name
   written in that language (`{ code: 'de', name: 'Deutsch' }`), and add it to `CATALOGS`.

The language then shows up on the first-launch screen and in Settings → Language and units. Dates and
numbers follow it by themselves (`Intl`).

## 2. Exercise library

Copy `server/src/import/library/en.json` to `server/src/import/library/<code>.json` and translate the
names and instructions. The file may be partial: exercises missing from it stay in English. Muscle and
type fixes are in `fixes.json` and do not depend on the language.

On the next start, the server adds the translations to the library and the devices receive them. The
exercise search finds a name in the language chosen and in English.

## 3. Fonts

Body text uses the system font, which covers every alphabet. Titles and numbers use Barlow Condensed,
whose Latin subset only is loaded (`client/src/main.tsx`), enough for most European languages. For
Vietnamese or other Latin letters, also import the matching subset (`@fontsource/barlow-condensed/vietnamese-700.css`,
`latin-ext-700.css`), for each weight already imported. Barlow Condensed has no Cyrillic or Greek: those
titles fall back to the system font.

## 4. Checking

```sh
npm run typecheck
npm test
```

The tests flag unknown keys and `{placeholders}` that do not match English (`client/test/i18n.test.ts`),
and check that the library files are valid (`server/test/exercises.test.ts`).

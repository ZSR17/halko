# Ajouter une langue

Halko est en anglais et en français. L'anglais sert de référence : un texte absent d'une autre langue
s'affiche en anglais, donc une traduction peut s'ajouter petit à petit sans rien casser.

## 1. Textes de l'app

1. Copier `shared/src/i18n/messages/en.json` en `shared/src/i18n/messages/<code>.json` (`de.json`,
   `es.json`…, le code ISO 639-1 à deux lettres) et traduire les valeurs. Garder les clés, et les
   `{variables}` telles quelles.
2. Les textes avec des pluriels sont des objets, avec une entrée par catégorie de pluriel de la langue
   (`one`, `few`, `many`, `other`…, telles que les donne [`Intl.PluralRules`](https://developer.mozilla.org/fr/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules)).
   `other` est toujours obligatoire.
3. Dans `shared/src/i18n/index.ts`, importer le fichier, ajouter une ligne à `LOCALES` avec le nom de la
   langue écrit dans cette langue (`{ code: 'de', name: 'Deutsch' }`), et l'ajouter à `CATALOGS`.

La langue apparaît alors sur l'écran de premier lancement et dans Réglages → Langue et unités. Les dates
et les nombres la suivent tout seuls (`Intl`).

## 2. Bibliothèque d'exercices

Copier `server/src/import/library/en.json` en `server/src/import/library/<code>.json` et traduire les
noms et les consignes. Le fichier peut être partiel : les exercices absents restent en anglais. Les
corrections de muscles et de types sont dans `fixes.json` et ne dépendent pas de la langue.

Au démarrage suivant, le serveur ajoute les traductions à la bibliothèque et les appareils les reçoivent.
La recherche d'exercices trouve un nom dans la langue choisie et en anglais.

## 3. Polices

Le texte courant utilise la police du système, qui couvre tous les alphabets. Les titres et les nombres
utilisent Barlow Condensed, dont seul le jeu de caractères latin est chargé (`client/src/main.tsx`),
suffisant pour la plupart des langues européennes. Pour le vietnamien ou d'autres lettres latines,
importer aussi le jeu correspondant (`@fontsource/barlow-condensed/vietnamese-700.css`,
`latin-ext-700.css`), pour chaque graisse déjà importée. Barlow Condensed n'a ni cyrillique ni grec : ces
titres s'affichent dans la police du système.

## 4. Vérifier

```sh
npm run typecheck
npm test
```

Les tests signalent les clés inconnues et les `{variables}` différentes de l'anglais
(`client/test/i18n.test.ts`), et vérifient que les fichiers de la bibliothèque sont valides
(`server/test/exercises.test.ts`).
